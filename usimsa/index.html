현재 구매의 비교값은 할인 적용 후 결제액으로 정하세요. 발급만 받은 쿠폰은 실제 사용하기 전까지 이번 주문의 현금 절약액이 아닙니다.

내 여행에는 어떤 유심사 혜택이 적용되나요?

같은 여행지라도 상품 유형과 회원의 구매 이력에 따라 확인할 조건이 달라집니다. 여행자 한 사람에게 필요한 상품을 기준으로 혜택을 골라보세요.

상품 유형과 가입 상태를 따로 판단하세요

  • eSIM 구매 회원전 상품 안내만으로 확정하지 말고 선택한 국가·요금제가 쿠폰 적용 목록에 있는지 확인하세요.
  • 실물 유심 구매 회원상품 할인액과 최종 결제 총액을 구분하세요. 추가 비용이 표시된다면 그 비용에도 할인이 적용되는지 확인하세요.
  • 처음 구매하는 회원첫 구매 여부와 신규 가입 여부는 다른 조건입니다. 이미 가입했어도 구매 이력이 없다면 첫 구매 혜택의 대상 조건을 확인하세요.
  • 동행자 상품 구매쿠폰 한 장을 여러 상품에 배분하는 구조로 생각하지 마세요. 추가 구매마다 사용 가능한 쿠폰이 남아 있는지 확인하세요.

여행 일수는 할인율보다 상품 선택에 먼저 반영하세요

계산용으로 6일 상품을 24,000원, 8일 상품을 30,000원이라고 가정하면, 25% 할인 후 각각 18,000원과 22,500원입니다. 상품 일수로 나눈 금액은 각각 3,000원과 약 2,813원이지만, 여행이 6일이라면 8일 상품에 4,500원을 더 지출하게 됩니다.

구매 판단같은 국가·데이터 조건으로 6일 동안 충분히 사용할 수 있다는 가정에서는 18,000원 상품의 총지출이 더 적습니다. 하루당 금액이 낮아져도 필요 없는 일수를 추가하면 총액은 늘어납니다.

유심사 할인코드는 어디에 넣나요?

유심사 할인코드는 웹 쿠폰함에 먼저 등록하고, 주문 결제에서 해당 쿠폰을 선택하는 순서로 사용합니다. 등록 완료와 할인 적용 완료를 구분하세요.

쿠폰함에 등록한 뒤 구매 상품에 연결하세요

  1. 유심사 공식 홈페이지에서 구매할 회원 계정으로 로그인하세요.
  2. [프로필]에서 [쿠폰]을 열고 상단 쿠폰 번호 입력 칸에 할인코드를 입력한 뒤 [등록]을 누르세요.
  3. 등록된 쿠폰의 [적용 상품/국가]를 열어 선택할 상품이 포함되는지 확인하세요.
  4. 상품 1개를 선택해 결제를 진행하고, 등록된 쿠폰을 결제 페이지에서 선택하세요.

결제를 확정하기 전에 차감 결과를 확인하세요

쿠폰이 목록에 보이는 것만으로 결제액이 줄었다고 판단하지 마세요. 주문할 요금제와 적용된 쿠폰, 할인액을 함께 확인한 뒤 보유 적립금을 입력하세요. 적립금을 사용했다면 사용액까지 반영된 최종 금액을 확인하세요.

유심사 할인코드가 안 될 때는 어떻게 하나요?

오류가 발생한 화면부터 구분하면 다시 확인할 조건이 줄어듭니다. 등록 실패, 상품 선택 불가, 적립금 차감 실패를 순서대로 점검하세요.

  1. 쿠폰함에 등록되지 않으면 입력값과 유효기간을 확인하세요

    등록 단계
    • 입력 정보
      불필요한 공백이나 누락된 문자가 없는지 확인하세요. 제휴 할인코드는 문자열이 바뀔 수 있으므로 이전에 저장한 값을 계속 사용하지 마세요. 앱에서 적용되지 않는다면 웹에 로그인해 등록을 진행하세요.

  2. 결제에서 선택되지 않으면 상품과 주문 구성을 확인하세요

    선택 단계
    • 적용 조건
      쿠폰의 적용 국가와 상품을 대조하고, 상품 1개를 결제하는 상태인지 확인하세요. 결제 금액은 쿠폰 할인액 이상이어야 합니다. 최소 결제 금액이나 할인 한도가 쿠폰함에 표시된다면 등록된 쿠폰의 조건으로 판단하세요.

  3. 적립금이 전부 차감되지 않으면 사용 단위를 확인하세요

    차감 단계
    • 잔액 점검
      보유 잔액이 1,450원이어도 사용 가능한 금액은 1,000원 단위입니다. 1,450원 전체를 입력하는 대신 1,000원을 선택하고, 소멸 예정 금액과 사용 가능한 잔액을 확인하세요.

오류 확인계속 실패하면 상품명·선택 요금제·오류 문구를 기록해 고객센터에 확인하세요. 원인이 밝혀지기 전에는 결제 후 소급 할인을 받을 수 있다고 가정하지 마세요.

유심사에서 함께 받는 할인은 무엇인가요?

쿠폰 할인과 적립금 차감은 함께 사용할 수 있습니다. 다만 이미 받은 잔액과 이번 구매로 나중에 받을 적립금은 계산에서 분리하세요.

다음 구매에서 쓸 잔액은 실제 적립 내역으로 계산하세요

3% 적립의 정확한 기준 금액이 쿠폰·적립금 사용 전후 중 어느 금액인지는 제공된 안내에 명시되지 않았습니다. 따라서 결제 총액에 곧바로 3%를 곱해 확정 잔액으로 안내할 수 없습니다. 구매 후 적립 내역에 표시된 금액을 확인하세요.

사용 단위에 도달하는 경우

기존 적립금 700원에 새 적립금 450원이 실제로 지급되었다고 가정하면 합계는 1,150원입니다. 다음 주문에서 1,000원을 사용하면 150원이 남습니다. 두 금액 모두 소멸하지 않고 사용 가능한 상태라는 전제입니다.

가입 적립금과 초대 적립금을 합산하기 전에 실제 지급 내역을 확인하세요. 초대한 사람의 보상까지 내 결제에 사용할 잔액으로 더하지 마세요.
